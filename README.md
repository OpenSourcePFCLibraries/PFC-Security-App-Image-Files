Image files used by the PFC Security applications (the Security Administrator and the Security Scanner), and their resource files, `pfcsecurity_admin.pbr` and `pfcsecsc.pbr`.

## Which versions of PFC use these files

| Version | Its images |
|---|---|
| [2022](https://github.com/OpenSourcePFCLibraries/2022) | **This repository.** Add its folder to the system path or to PowerBuilder's application path; the Security Administrator's project names `pfcsecurity_admin.pbr`. |
| [2019](https://github.com/OpenSourcePFCLibraries/2019) | The same images, in that repository. It doesn't need this repository. |
| [2025-Solution](https://github.com/OpenSourcePFCLibraries/2025-Solution) and [2025-Workspace](https://github.com/OpenSourcePFCLibraries/2025-Workspace) | Current images (Fluent UI System Icons) in `security administrator/images`. They don't use this repository. |
